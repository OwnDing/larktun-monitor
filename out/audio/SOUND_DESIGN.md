# 云雀通 01 · 声音设计与混音说明（阶段 I）

原创程序化音轨。全部音乐、音效与环境声由 `film/sound_design.py` 用 NumPy 合成（DSP 在 `film/audio_dsp.py`，音色在 `film/sound_kit.py`）。没有第三方采样、外部音乐或口播，随机种子固定，可复现。规格来自 `out/audio_cue_sheet.md`；表中“新增”是音效表未列、但与画面动作逐帧对应的细节。

## 交付

| 文件 | 内容 |
|---|---|
| `out/larktun_01_clean_audio.mp4` | 无叙事字幕版 + 音轨 |
| `out/larktun_01_sub_audio.mp4` | 带字幕版 + 音轨 |
| `out/audio/larktun_01_mix.wav` | 母带：48 kHz / 24-bit / 立体声，1,920,000 采样 = 40.000 s |
| `out/audio/stems/{music,sfx,ambience,ding}.wav` | 32-bit float 分轨；已含母带增益与限幅曲线，四轨相加即母带 |
| `out/audio/sound_manifest.json` | 全部 322 个 cue 的帧号、采样点、增益、声像、混响发送，以及响度和文件哈希 |
| `out/gates/I/` | 验收报告与三张频谱图 |

两版有声 MP4 的视频数据包与已验收的无声版逐包相同（`-c:v copy`），只增加 AAC-LC 256 kbps / 48 kHz 立体声音轨。无声版 `out/larktun_01_clean.mp4`、`out/larktun_01_sub.mp4` 原样保留。

## 时间规则

- 帧 f 起点 = 采样 `(f-1)×1600`（48 kHz / 30 fps）。每个 cue 的第一个采样点落在所属帧的第一个采样点。
- 音乐 90 BPM，一拍 = 20 帧，拍点在帧 `1+20k`；541、901、1081、1141 都在拍点上。
- **冷段 1–540**：D 小调。541 帧前 4 ms 升余弦收尾；冷段所有声音及其混响、回声尾巴，从 541 帧第一个采样点起精确为 0。
- **541–549**：只有一声“叮”（A6）。A 是 D 小调的五音，也是 F 大调的三音，作为两段之间的枢纽音。
- **暖段 550 起**：F 大调，1 ms 淡入。和声 Fmaj9 → Am7 → B♭maj9 → Csus4–C → Dm9 → B♭maj9 → Gm9 → C9sus4 → Fmaj9。
- 同一动机：冷段 A4–D5–E5–F5（玻璃音色），暖段 C5–F5–G5–A5（电钢琴），S12 为八音盒 C6–F6–G6–A6。
- 39.0–39.5 s 升余弦收尾，1186–1200 帧为数字零。

- 集成响度 **−14.0 LUFS**，真峰值 **−1.1 dBTP**（FFmpeg ebur128，4× 过采样复核同为 −1.1），LRA 6.0 LU，限幅最大削减 1.01 dB。

## 修改与重做

在仓库根目录执行，约 1 分钟。不需要重渲 Blender、字幕或画面。

```bash
FILM_PY=/Users/ownding/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3
"$FILM_PY" film/sound_design.py                   # 合成、混音、母带、分轨、manifest
"$FILM_PY" film/validate_audio.py --stage master  # 静音窗口、响度、分轨求和、逐采样同步、频谱图
"$FILM_PY" film/mux_audio.py                      # 视频流复制，封装两版有声 MP4
"$FILM_PY" film/validate_audio.py --stage mux     # 视频逐包一致、A/V 偏移、解码响度
```

- 调某个声音的音量或位置：改 `film/sound_design.py` 里对应 `cue(...)` 的增益（dB）、声像或帧号。
- 换音色：改 `film/sound_kit.py`。混响在 `REVERBS`，目标响度在 `TARGET_LUFS`。
- `cue()` 会拒绝在 541–549 放入除“叮”以外的任何声音。

## 限制与说明

- 音色为程序化合成，质感不等同于专业作曲与拟音。需要更高质感时，可把分轨和 `sound_manifest.json` 交给声音设计师替换局部。
- **本阶段混音依据客观测量完成（逐镜响度、频谱、分轨同步互相关），制作过程中未经人耳试听。** 审美判断需要人工在手机外放和耳机上各听一遍。
- 按创意脚本推荐的方案，没有口播。
- −14 LUFS 是短视频平台常用的目标值，各平台仍会做自己的响度归一化。
- 暖段音乐总线的 tape wow 是 0–0.95 ms 分数延迟，暖段音乐因此比帧起点最多晚 0.95 ms（实测 0.81 ms），远低于可感知的音画不同步。所有音效与“叮”逐采样点对齐。
