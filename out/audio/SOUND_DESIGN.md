# 云雀通 01 · 声音设计、字幕旁白与混音说明（阶段 I）

原创音轨加字幕旁白：
- **音乐、音效与环境声**：由 `film/sound_design.py` 用 NumPy 程序化合成（`audio_dsp.py`、`sound_kit.py`），没有第三方采样或外部音乐。
- **字幕旁白**：由 `film/voice_tts.py` 在本机用开源普通话 TTS 生成，每句都放在对应字幕出现的帧内。

随机种子固定，结果可复现。

## 字幕旁白

- **声音**：Kokoro-82M v1.1-zh（Apache-2.0，可商用），男声 zm_029。模型来源、哈希与许可证见 `assets/voice/provenance.json`。
  - 从 45 个男声中试听选出：基频中位约 106 Hz，音高起伏窄，符合脚本“低沉、不煽情”。
  - 14 句的 ASR 转写不看声调时全部正确。
- **没有用 macOS 自带语音**：苹果许可证只允许把系统语音用于个人非商业用途。
- **时间规则**：
  - 每句从字幕出现后 1 帧开始（S01 为第 6 帧），在本镜结束前 2 帧内说完。
  - 放不下的句子只提高本句语速，最高 1.26 倍（S11）。
- **541–549 帧静音不被打破**：S07 旁白 552 帧才开口。S06 旁白 533 帧说完，闪避提前释放，冷色段在 541 帧硬切前重新涌起。
- **闪避**：旁白说话时，音乐 −9 dB，并在 2.5 kHz 附近削出空间；环境声 −8 dB；音效 −6 dB。“叮”不受影响。
- **文案**：按创意脚本的口播列，有三处和屏幕字幕不同：
  - S06 字幕“×3 台摄像头”读作“三台摄像头，乘十二个月”，对应画面上的 ×12 个月。
  - S13 只有角标和卡片，读角标“装完就能用”。
  - S14 字幕只在 1149–1185 帧的 1.2 秒 Logo 定格内出现，放不下整句口号。所以只读“云雀通”，口号和网址只以字幕呈现。

- **语速**：相对模型自然语速的倍数，基准为 0.95。
- **高出底层**：旁白与同时段音乐、音效、环境声之间的近似 K 加权响度差。

**可懂度核验**：用 SenseVoice 语音识别转写成片 MP4（人声 + 音乐 + 音效）中的每句旁白，报告在 `out/gates/I/voice_asr_mix.json`。
- 不看声调时，14 句的拼音音节全部识别正确。
- 被识别成的同音字不影响读音：家→佳、它→他、雀→却。
- 只有一处声调分歧：“月费”被识别为“岳飞”，可能是识别模型偏向常见人名，需要人工试听确认。

## 时间规则（音乐与音效）

- 帧 f 起点 = 采样 `(f-1)×1600`（48 kHz / 30 fps）。每个 cue 的第一个采样点落在所属帧的第一个采样点。
- 音乐 90 BPM，一拍 = 20 帧，拍点在帧 `1+20k`。
- **冷段 1–540**：D 小调。541 帧前 4 ms 收尾，冷段所有声音及其混响、回声尾巴（含 S06 旁白的尾巴）从 541 帧起精确为 0。
- **541–549**：只有一声“叮”（A6，D 小调五音 = F 大调三音）。
- **暖段 550 起**：F 大调。和声 Fmaj9 → Am7 → B♭maj9 → Csus4–C → Dm9 → B♭maj9 → Gm9 → C9sus4 → Fmaj9。
- 同一动机：冷段 A4–D5–E5–F5（玻璃音色），暖段 C5–F5–G5–A5（电钢琴），S12 为八音盒。
- 39.0–39.5 s 收尾，1186–1200 帧为数字零。

## 响度与母带

- 集成响度 **−14.0 LUFS**，真峰值 **−1.3 dBTP**（4× 过采样复核 −1.27），LRA 2.2 LU，没有触发限幅。
- 旁白居中，立体声左右相关 0.93，折叠单声道损失 0.16 dB。“叮”的瞬时最大 −11.9 LUFS，与旁白齐平。
- 各镜瞬时最大响度（M，LUFS）：S01 −12.2、S02 −12.4、S03 −11.4、S04 −12.1、S05 −11.8、S06 −11.3、S07 −12.0、S08 −10.9、S09 −11.3、S10 −12.4、S11 −11.5、S12 −13.2、S13 −12.2、S14 −11.5。
- 两版 MP4 解码后响度和真峰值与母带一致，与母带的互相关偏移为 0 采样，黑场为数字零。

## 修改与重做

在仓库根目录执行。旁白环境与模型只需准备一次；模型下载地址与 SHA-256 见 `assets/voice/provenance.json`，解压到 `assets/voice/`。

```bash
python3 -m venv .venv-voice && .venv-voice/bin/pip install -r film/voice_requirements.txt
FILM_PY=/Users/ownding/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3
.venv-voice/bin/python film/voice_tts.py          # 逐句生成旁白、适配字幕窗口、ASR 自检
"$FILM_PY" film/sound_design.py                   # 合成、放置旁白、闪避、母带、分轨、manifest
"$FILM_PY" film/validate_audio.py --stage master  # 静音窗口、响度、分轨求和、同步、旁白在字幕帧内
"$FILM_PY" film/mux_audio.py                      # 视频流复制，封装两版有声 MP4
"$FILM_PY" film/validate_audio.py --stage mux     # 视频逐包一致、A/V 偏移、解码响度
.venv-voice/bin/python film/voice_tts.py --check  # 成片中每句旁白的 ASR 转写
```

- **改旁白文案或时间**：改 `film/voice_tts.py` 里的 `NARRATION`，每行是镜号、文本、起始帧、最后允许帧。窗口必须在该字幕出现的帧内，脚本会检查。
- **换声音**：改 `SPEAKER`（v1.1-zh 的 103 个音色中，58–102 为男声 zm_*，3–57 为女声 zf_*）。
- **调旁白音量和闪避**：改 `film/sound_design.py` 的 `VOICE_GAIN`、`DUCK`。
- **调其他声音**：改对应 `cue(...)` 的增益、声像、帧号；音色在 `film/sound_kit.py`。
- **真人配音**：可以按同样的帧窗口录制，替换 `out/audio/voice/Sxx.wav`，保留 `voice_manifest.json` 的起始帧，再从 `sound_design.py` 起重跑。

## 限制与说明

- 旁白是开源 TTS 合成，自然度不等同于专业配音员。
  - 长句为放进 3 秒镜头被提速（S04 1.16×、S11 1.26×），脚本希望的“慢”只在短句上做到。
  - 需要正式投放级质感时，建议真人按上表时间录制替换。
- **本阶段混音依据客观测量完成（逐镜响度、频谱、同步互相关、成片 ASR），制作过程中未经人耳试听。** 请在手机外放和耳机上各听一遍。
- 旁白几乎贯穿全片，音乐和音效在说话时被压低，音乐的起伏退居其次。偏好的人声 / 音乐比例需要试听后微调。
- S14 只读“云雀通”，S13 读角标，S06 措辞与字幕略有差异，原因见上文。
- 暖段音乐总线的 tape wow 使暖段音乐最多晚 0.95 ms（实测 0.81 ms），远低于可感知的音画不同步；音效、“叮”和旁白都逐采样点对齐。
- −14 LUFS 是短视频平台常用的目标值，各平台仍会做自己的响度归一化。
